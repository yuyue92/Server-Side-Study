# 在线教育平台后端接口调试前端

这是一个纯静态单页调试台，配套此前的 Go + Gin + GORM + SQLite 后端项目使用。

## 功能覆盖

- 后端健康检查 `/healthz`
- 用户注册与登录
- 自动保存教师 Token / 学生 Token
- 教师创建课程
- 教师创建章节
- 学生报名课程
- 学生更新学习进度
- 学生查询课程进度汇总
- 公开课程列表与课程详情查询
- 一键全流程验证
- 请求结果控制台与最近请求历史

## 使用方式

### 1. 先启动后端

在后端项目目录中执行：

```bash
go mod tidy
go run ./cmd/server
```

默认后端地址：

```text
http://127.0.0.1:8080
```

### 2. 打开前端页面

可直接双击：

```text
index.html
```

也可以在当前目录开一个静态服务器：

```bash
python -m http.server 5500
```

然后浏览器访问：

```text
http://127.0.0.1:5500
```

### 3. 推荐验证方式

直接点击页面右上区域：

```text
一键全流程验证
```

页面会自动完成：

1. 注册教师
2. 注册学生
3. 教师创建课程
4. 教师创建章节
5. 学生报名课程
6. 学生更新学习进度
7. 查询课程进度汇总

验证成功后，页面会自动回填课程 ID、章节 ID，并保存教师与学生 Token。
